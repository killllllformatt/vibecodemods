Trust No One for Gimkit

See every player’s real role (impostor vs detective) and the correct answer.

Trust No One ↑ Drag this button onto your bookmarks bar

Install

  1. Show your bookmarks bar: Ctrl Shift B (⌘ Shift B on Mac).
  2. Drag the Trust No One button above onto the bar.
  3. Open Gimkit and start or join a Trust No One game.
  4. Click the bookmark.

Can't drag it? (school Chromebooks, phones)

  1. Copy the code below.
  2. Bookmark any page (Ctrl D), then edit that bookmark.
  3. Name it Trust No One and paste the code into the URL box.

Using it

  1. Hide or show the panel with Insert.
  2. The list appears top-right within a few seconds of joining or injecting mid-game.
  3. Toggle auto-answer with F8 (off by default).
  4. Reload the page to clear it.

What's inside

Role revealLive list of who’s an impostor 🔪 and who’s a detective 🔍, updated after every ejection.
Answer helperOutlines the correct answer in green so you never miss a question.
Auto-answerPress F8 to toggle: answers correctly and clicks Continue on its own.
You markerHighlights your own row so you instantly know your role.
Read-only reveal — it reads what the server already sent to your browser and sends nothing back. Auto-answer does click for you, which is visible in your own score.
