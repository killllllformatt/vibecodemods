Snowy Survival ESP for Gimkit

Zombie/human tracker for Snowy Survival: who’s infected, health bars and a live roster.

Snowy Survival ESP ↑ Drag this button onto your bookmarks bar

Install

  1. Show your bookmarks bar: Ctrl Shift B (⌘ Shift B on Mac).
  2. Drag the Snowy Survival ESP button above onto the bar.
  3. Open Gimkit and start or join a Snowy Survival game.
  4. Click the bookmark.

Can't drag it? (school Chromebooks, phones)

  1. Copy the code below.
  2. Bookmark any page (Ctrl D), then edit that bookmark.
  3. Name it Snowy Survival ESP and paste the code into the URL box.

Using it

  1. Hide or show the overlay with Insert.
  2. Click the bookmark again to remove it.
  3. Join or host a Snowy Survival game first, then click the bookmark.
  4. Click the bookmark again to remove it completely.
